# Sirdaryo viloyati Yoshlar texnoparki — rasmiy sayt

Сайт молодёжного технопарка Сырдарьинской области: стартапы, лаборатории, инвесторы и главная функция — **бизнесмены оставляют проблемы своих предприятий, технопарк предлагает инновационное решение**.

**Стек:** React 18 · Vite 5 · Tailwind CSS 3 · Three.js (@react-three/fiber + drei) · Motion · Lenis
**Языки:** узбекский (латиница), узбекский (кириллица), русский.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

В режиме разработки формы не отправляются на сервер — данные выводятся в консоль браузера.

## ⚙️ Что заменить перед запуском

Весь контент хранится в `src/data/` — менять код страниц не нужно.

- `src/data/site.js` — **телефон, e-mail, Telegram, соцсети, адрес, координаты карты, статистика** (сейчас там заглушки и примерные цифры).
- `src/data/challenges.js` — задачи в «Банке задач» (сейчас примерные).
- `src/data/business.js` — кейсы (`CASES`), каталог решений (`SOLUTIONS`), FAQ для бизнеса.
- `src/data/rooms.js` — помещения и оборудование.
- `src/data/content.js` — программы, события (`EVENTS`), FAQ и прочие тексты.

Тексты пишутся парой `L('узбекский кириллицей', 'русский')`; латиница формируется автоматически (`src/i18n/translit.js`).

## Заявки: куда они приходят

Сайт рассчитан на хостинг **Netlify** (настройки в `netlify.toml`). Все 6 форм работают через **Netlify Forms** без отдельного бэкенда:

1. Задеплойте сайт на Netlify (Build command: `npm run build`, Publish directory: `dist`).
2. Заявки появятся в панели Netlify → **Forms** (`biznes-muammo`, `yechim-taklifi`, `startap-ariza`, `xona-bron`, `investor-ariza`, `aloqa`). Там же можно включить уведомления на e-mail.
3. **Уведомления в Telegram** (по желанию): создайте бота через @BotFather, добавьте его в группу сотрудников и задайте в Netlify → Site configuration → Environment variables:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `TELEGRAM_CHAT_ID` — ID группы (например `-1001234567890`)

   Функция `netlify/functions/submission-created.js` будет пересылать каждую новую заявку в эту группу.

> Если меняете поля форм в `src/components/forms/*`, обновите и скрытые формы в `index.html` — по ним Netlify определяет поля.
